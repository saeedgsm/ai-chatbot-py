# Neon Bot

یک ربات گفت‌وگوی خط فرمان با پایتون است که از API سازگار با OpenAI در Groq استفاده می‌کند. ربات گفتگو را در طول اجرای برنامه نگه می‌دارد و پس از پایان، تاریخچهٔ پیام‌ها و تعداد کل توکن‌های مصرف‌شده را نمایش می‌دهد.

## پیش‌نیازها

- Python 3.10
- یک API key از Groq
- Pipenv

## راه‌اندازی

۱. وابستگی‌ها را نصب کنید:

```bash
pipenv install
```

۲. فایل نمونهٔ متغیرهای محیطی را به `.env` کپی کنید و مقدار `GROQ_API_KEY` را با API key خود جایگزین کنید:

```text
GROQ_API_KEY=your_groq_api_key
```

۳. برنامه را اجرا کنید:

```bash
pipenv run python chat_bot.py
```

## استفاده

پیام خود را پس از نمایش `You:` وارد کنید. برای پایان گفتگو `q` را وارد کنید. پس از خروج، تاریخچهٔ گفتگو و مجموع توکن‌های مصرف‌شده نمایش داده می‌شود.

ربات از مدل `openai/gpt-oss-120b` استفاده می‌کند و پاسخ‌ها را با حداکثر ۱۰۰ توکن تولید می‌کند.
